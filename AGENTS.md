# Typehug

## Agent skills

### Issue tracker

Track issues and specs in GitHub Issues at `alexszczurek/typehug` using `gh`. Before reading or updating tickets, read `docs/agents/issue-tracker.md`.

### Triage labels

Use the five canonical triage labels as-is. Before triaging an issue, read the role mapping in `docs/agents/triage-labels.md`.

### Domain docs

Use one shared `CONTEXT.md` and `docs/adr/` at the repository root. Before exploring domain concepts or changing their design, read `docs/agents/domain.md`.
