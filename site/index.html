Installation

Choose the language you need. The examples below follow your selection.

npm install @typehug/pl

Polish rules and the shared engine. No English rules included.

ESM · TypeScript · Node.js 22+

Usage

Pass in your text. Typehug replaces selected spaces with nonbreaking spaces.

Plain text

import { glue } from "@typehug/pl";

glue("Idę w dobrym kierunku.");
Output

Idę w dobrym kierunku.

Returns a string with Unicode nonbreaking spaces. Render it as text, including in React.

HTML

import { glueHtml } from "@typehug/pl/html";

glueHtml("Idę w <b>dobrym kierunku</b>.");
Output

Idę w dobrym kierunku.

Joins across inline formatting. Importing /html loads the parser.

Formatted runs

import { glueRuns } from "@typehug/pl";

glueRuns([
  { text: "Idę w " },
  { text: "dobrym kierunku.", bold: true },
]);
Output

Idę w dobrym kierunku.

Preserves formatting metadata and leaves the input objects unchanged.

Examples use Polish. With @typehug/all, pass { locale: "pl" } or { locale: "en" } as the second argument. HTML is parsed and serialized, so entity spellings and markup may normalize.
